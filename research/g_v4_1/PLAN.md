# G V4.1 预注册方案

## 唯一目标与边界

检验 G0 从零自博弈是否能继续提升真实棋力，并逐步接近冻结 A。只使用 9×9 原规则、G0 自身生成的 PUCT-64 对弈状态、根访问分布与终局胜负标签。冻结 A/B/C/E/F 及历史模型、数据和分支。训练及推理均不使用任何 A/B/C/E/F 教师、模仿标签、人工战术奖励或规则战术补丁。正式晋级与盲测均采用同一 PUCT-64；128/256、消融只用于诊断，不计作网络学习收益。

## 先验诊断结论与单因素假设

历史 V4 的 G0 续训 `B-G0-v3-champion-continue@100000` 对冻结 V3 G0@20K 裸网络 22-0-2（91.7%），而 PUCT-64 为 4-0-20（16.7%）。新做的 8 个配对开局交叉赛中，按「候选模式/旧冠军模式」：network/network 14-0-2；network/PUCT 1-0-15；PUCT/network 14-0-2；PUCT/PUCT 3-0-13。四组均属诊断样本，不作稳定棋力声明。

规则枚举的 V3 G0@20K 题集中，8 个对称直接胜点题上裸网络与默认 PUCT-64 均为 0/8。逐根记录表明：目标胜点先验平均排名45.4/81，PUCT-64 平均只访问目标1次；将价值头输出置零的诊断消融为8/8，将 `c_puct` 从1.5改为5为7/8，256模拟为8/8。对 V4 B@100K，目标胜点先验平均仅1.66e-6，64/128/256模拟及 `c_puct` 3/5/10 都没有访问目标；因此不能仅归因于模拟量，策略先验塌缩与价值头在战术位置上的估值共同可疑。消融题集仅来自4个母题的D4变换。

V4 B 的自博弈中位日志统计为黑胜76.9%、白胜23.1%，均局长25.8手、访问策略熵2.46；V3起点样本为黑胜54.1%、白胜45.9%，均局长32.1手、熵3.45。按局采样会使短局中的每个状态获得更大权重。以下单因素分别检验状态权重、胜方颜色偏斜及学习率；历史 G0 对手池列为未测试的后续假设。

## 公平起点与四个训练臂

所有臂使用相同冻结 `G0-seed-510901@20000` 权重、V3 前20,000个自博弈状态构成的同一回放初始集、相同网络（32通道、2残差块）、BN running statistics 冻结、AdamW、余弦调度、每16状态一次更新、batch 16、PUCT-64、温度与开局表。无法恢复精确 20K 优化器状态；所有臂统一采用权重继承、优化器/调度器重新初始化，并逐条记录。

| 臂 | 唯一变化 | 注册值 |
| --- | --- | --- |
| control_v4 | V4 原训练方式 | 游戏均匀采样；LR 1e-4；当前 G0 对当前 G0 |
| state_uniform | 回放采样单位 | 全部状态行均匀抽样；LR 1e-4 |
| winner_balanced | 回放游戏权重 | 自博弈黑胜/白胜等权抽样，平局保留其经验比例；LR 1e-4 |
| low_lr | 学习率 | LR 3e-5；游戏均匀采样 |

每臂最多新增10,000状态，合计上限40,000。共享确定性开局和随机数计划，避免给某臂挑选更有利开局。每局完成即写入完整棋谱；优化器按每16个预算状态更新。未经预注册，不增加臂、不改变搜索设置、不追加训练预算。

## 开局、评估及晋级

冻结新的训练/开发/盲测开局表，D4去重并排除 V3/V4 已用开局。训练表为空盘/合法4手随机局面各半。每个检查点以开发集固定换色比较：裸网络与 PUCT-64 对 V3 G0@20K、冻结 A、冻结 B；所有四臂 PUCT-64 两两比较。检查点选择只用开发集。

挑战旧冠军的预注册晋级条件：PUCT-64 总得分率至少62.5%，按配对开局bootstrap的95%区间下限严格高于50%，且黑白各自得分率不低于50%。未满足时保留原冠军；最佳开发候选仍会进入一次性盲测，但盲测不得回流调参。独立盲测使用20组新开局、双方交换黑白，至少40局；冻结 V3 G0@20K与开发集选出的候选，在 network/network 及 PUCT/PUCT 评估中对 A、B，并用PUCT-64直接交手。对A只有得分率>50%且配对95%区间下限>50%才称为有统计支持的超越。

## 资源、停止与恢复

CPU硬上限6 CPU小时，CPU-only，torch单线程。正式训练前记录 CPU/memory/disk、PUCT 16/32/64/128/256、完整自博弈、训练吞吐与评估速度，报告乐观/中性/保守总耗时；预算含诊断、训练、评估、测试与审计。超预算则先完成诊断和最有价值的受控路线，报告实际未完成项，不扩大上限。

Drive独立目录 `WuziQ G V4.1 Recovery`。有效运行累计时长按1、2、4、6、10、16、26小时递增间隔；关键阶段可提前存档。新包必须上传、回下载、SHA-256一致并在空目录恢复通过，才删除上一包。未通过时保留旧包。快照与恢复入口只涵盖本实验必要的配置、代码版本、模型/优化器/经验池、随机状态、进度及完整结果。

## 结果解释

预注册区分：同一检查点 network 对 PUCT 是搜索收益；同一模式下训练前后是学习收益；checkpoint 对旧冠军的换色胜率是冠军晋级证据。损失、root value 或战术题改进不替代棋力。盲测一旦启动只运行一次，不能用于挑模型。结果小样本、开局依赖与 G0 单初始化的限制须在报告中明确。
