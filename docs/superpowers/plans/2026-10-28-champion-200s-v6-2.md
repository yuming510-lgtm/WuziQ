# V6.2 200-second Champion Tournament Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete and publish six fresh, replay-validated 200-second-per-move games among frozen V6 C, D, and E5.

**Architecture:** A V6.2-specific schedule, runner, validator, reporting, and snapshot layer calls the V6 `play_game` engine and existing V6 board validation. All new artifacts live under `research/v6_2`; algorithm implementation and V6 results remain unchanged.

**Tech Stack:** Python 3, existing V6 research modules, pytest, JSON/JSONL, SVG, Google Drive connector, Git.

**Spec:** `docs/superpowers/specs/2026-10-28-champion-200s-v6-2-design.md`

## Global Constraints

- Baseline: `0c7e0e5881b8e0bcd2bdd8c07c247912ad86783d`.
- Branch: `research/champion-200s-v6-2`.
- Board: 9×9; frozen players: C, D, E5; per-move maximum: 200 seconds.
- Exactly three pairs (C–D, C–E5, D–E5), two games each, same opening and swapped colors, six actual games.
- Score: win 1, draw 0.5, loss 0; exact top-score tie means joint champions.
- Opening 731201: B(4,4), W(3,5), B(5,3), W(2,6); prove legal, nonterminal, and absent from V6 games.
- No historical-result reuse, training, tuning, or core algorithm edits.
- Every game is persisted only after complete play and successful replay validation; interrupted games restart from the beginning.
- Do not delete or replace any V6 Drive snapshot; rotate only V6.2 files after the replacement passes restore verification.

## Review Focus

- A stale or altered engine source must fail the V6 pin check before any official game starts.
- The same opening must be legal and identical across all three pairs; its second game must swap colors.
- Resuming must skip only complete, validated game IDs and never count a partial game.
- A reported timeout flag must reflect the engine result or an actual elapsed-time overrun, with every played move legal.
- Snapshot restore must reject file tampering and restore into an empty directory without changing V6 files.
