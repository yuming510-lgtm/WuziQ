# WuziQ G V4.2 Implementation Plan

> **For agentic workers:** implement the registered tasks inline, test-first, and preserve the experiment ledger.

**Goal:** Diagnose and improve G0's PUCT-64 strength through generic search calibration and controlled self-play training.

**Architecture:** Preserve the existing network and PUCT default. Add opt-in prior/value search parameters, then a branch-locked V4.2 experiment package for historical checkpoint screening, tactic/search diagnostics, three one-factor G0 training arms, paired evaluation, audit, snapshots, and Chinese reporting.

**Tech Stack:** Python 3.12, PyTorch, NumPy, pytest, existing Gomoku/PUCT/self-play modules, GitHub and Google Drive connectors.

**Spec:** `docs/superpowers/specs/2026-11-03-g-v4-2-design.md`

## Global Constraints

- Base commit: `4dd0c449c7a4afe1a4f68b3e2a234cdd70e186df`; branch: `research/alphazero-g-v4-2`.
- Formal model comparisons use PUCT-64; 128/256 are diagnostic only.
- No A/B/C/E/F data or weights in training; no teacher labels, handcrafted rewards, or tactical inference patches.
- Three equal arms, 10K states each unless measured preflight requires equal lower budgets; total hard cap 40K states and 5 CPU hours.
- Held-out paired blind openings are frozen before training and never used for selection.
- Only one latest verified snapshot may remain in the dedicated V4.2 Drive folder.

## Review Focus

- Search defaults must remain numerically identical for all previous branches — test default results and explicit neutral parameters agree.
- Search calibration may not alter exact terminal values or legal masks — test terminal wins/draws and illegal-cell probability remain unchanged.
- Historical G0 pool games must never feed non-G0 models or opponent-turn labels — test learner-side sample identity and result perspective.
- Resume after a completed game must not duplicate its game ID or budgeted states — test crash-boundary reconciliation.
- Blind results must not participate in checkpoint/config selection — test plan IDs and evaluator phase guards.
