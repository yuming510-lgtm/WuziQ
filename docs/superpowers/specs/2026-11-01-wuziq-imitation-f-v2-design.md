# WuziQ F V2 设计：有针对性的监督续训

## 意图

以 F V1 commit `d33e653a29a5f24aecf6c5e25d09b137a68f4c01` 为冻结基线，继续监督训练现有 9×9 CNN，让纯神经网络策略提高对规则 AI A 的实战得分。F V1 权重、数据和报告只作对照；本轮不启动 G 强化学习。

## 目标与边界

- 延用 F V1 的 3 平面输入、81 位策略头、价值头、加载及推理 API，不扩大网络。
- 训练只使用 F V1 的训练分区和新生成的训练开局；原验证集保持早停用途，原盲测集不参与训练或模型选择。
- 从 F V1 对 A 的输局中归纳失误类型，使用 C/E5 在新 F1 对 A 训练局面上的监督标签，并以五连规则精确标记一步胜点和唯一必防点。
- 精确战术信息只作为训练标签，不进入 F2 推理决策。F2 每步仅做网络前向、合法空位掩码、在合法动作中选网络最高概率落点。
- 最大训练方案为两个独立 warm-start 试验，每个最多 60 轮、至少 30 轮、验证损失早停；只有开发赛程未达到预注册门槛时才运行第二方案。
- 固定开发开局用于有限候选模型选择；最终至少 20 个全新开局组，每组换色两局。F1/F2 使用相同最终棋谱赛程；只在训练选择结束后执行并封存最终赛果。
- 不改 A，不使用外部棋谱，不以击败 C 为目标，不将小样本结果描述为统计显著。

## 实现方案

### 数据

保留 V1 的历史数据、manifest、验证和盲测文件原样。预先生成互不相交的训练对局、开发对局及最终盲测开局组，并排除 V1 历史分区和旧评估开局组。训练对局由冻结 F1 与原 A 引擎进行；只采集 F1 轮到行棋的公开状态，由 C/E5 交替标注。用准确规则优先识别当前方直接成五；否则若对方只有一个下一手胜点，则生成唯一阻挡标签。普通状态保留 C/E5 标签。新增样本若规范状态撞上 V1 验证或盲测集则丢弃。

构建两个固定训练集：基础与 DAgger 新样本至少各出现一次；训练集内的直接取胜和单点必防状态过采样至约 30% 或 40%，并在两类间平衡。增强样本只来源于训练开局及 V1 train。记录原始唯一局面数、类别数、过采样行数和 SHA-256。

### 训练与选择

在现有训练器中增加可选 F1 初始化 checkpoint；恢复时继续核对数据、配置及初始化权重指纹。模型结构、masked policy loss、value loss、随机增强方式保持不变。配置冻结随机种子、warm-start SHA、训练集 SHA、epoch 上下限、早停 patience 与候选保存周期。候选 checkpoint 只用于开发赛程选择，不读取最终盲测结果。

F2 运行只有合法位置屏蔽，无规则优先级或搜索。开发赛程固定为 8 个开局组、每模型 16 局。每轮训练候选先用验证损失确定，再由开发得分从候选中选最佳。若首个方案最高开发得分低于 55%，最多再运行一个预注册的 40% 战术样本方案；总训练轮次封顶且不追加第三轮。

### 最终评估

冻结 F1 checkpoint 复制件和开发选出的单一 F2 checkpoint。最终盲测使用 20 个训练和开发均未使用的新开局组，每模型 40 局，逐开局黑白换色。按胜 1、平 0.5、负 0 计算得分率；报告胜平负、总体与黑白分项，并以开局组为单位做固定种子的配对 bootstrap 95% 区间及 F2−F1 配对差区间。只有区间下限高于 50% 才可称为本赛程下有清晰胜率证据；否则按探索结果报告。

同时在相同 F1 blind 数据上报告策略准确率、策略损失、价值 MAE、合法率、直接取胜/单点阻挡 top-k、CPU 推理中位数和 p95。复算每一条 F1/F2 棋谱，确认每个网络落点都等于该 checkpoint 在当时棋盘的 masked-policy argmax。

## 约束及由实现者决定

- A/B/C/E5 代码及 F1 checkpoint 均冻结；训练和比赛仅使用公开棋局信息。
- 机器资源由预检实测；无 GPU 时使用 CPU，不为赶时间降低最终样本数。
- 开局数量：16 个训练组、8 个开发组、20 个最终盲测组，固定种子和生成顺序；如果相撞，仅按确定性 seed 重抽并在配置中记录。
- 教师标注预算初定 200ms/手，预检可按实测代价调整一次后冻结；精确必胜/必防标签始终优先于教师选择。
- 每个阶段原子保存并按 Drive 累计有效运行小时 1、3、7、13、23、39、65、91……备份。上传新快照并下载校验、空目录恢复验证后再删旧快照。
- F2 checkpoint 必须可由 F1 的 `load_f_checkpoint` 和 `predict_policy_value` 加载。报告需明确 F2 是给 G 使用的网络先验与价值初始化；若战术防守仍弱，G 必须自行学习或搜索补强，F2 不可作为安全独立棋手。
